# Сборка и разработка

[README](../README.md)

## CLI и сборка

Для сборки нужны Git и **.NET SDK 10**. Зависимости UndertaleModLib 0.9.2.0 и Underanalyzer зафиксированы субмодулями:

```bash
git submodule update --init --recursive
dotnet build Patcher/DeltaTranslator.Patcher.csproj -c Release
```

```bash
dotnet run --project Patcher -- patch path/to/data.win path/to/patched.win
dotnet run --project Patcher -- verify path/to/patched.win
dotnet run --project Patcher -- list path/to/DELTARUNE
dotnet run --project Patcher -- install path/to/DELTARUNE --chapters 1,2
```

`patch` пишет в новый файл и не перезаписывает входной архив или существующий выходной файл. `list` выводит номера найденных глав. `install` без `--chapters` выбирает все найденные главы. Сначала он собирает и проверяет выбранные архивы, затем создаёт резервные копии и заменяет архивы. Повторная установка уже проверенного патча не меняет файлы. Не запускайте патчер одновременно с игрой, обновлением или другим патчером.

Для сборки GUI-установщика установите **Inno Setup 6.3+** и запустите из корня репозитория:

```powershell
.\installer\build-windows.ps1
```

Результаты: `artifacts/installer/DeltaTranslator-Setup-win-x64.exe` и `artifacts/patcher/` (автономный CLI с сопутствующими данными). Workflow **Patcher and installers** собирает и публикует эти артефакты после тестов. В них не входят игровые архивы. Патчер использует UndertaleModLib под GPLv3; при распространении бинарников предоставляйте соответствующие исходники и лицензии зависимостей.

Для графического установщика Linux и macOS используется Avalonia. Сборку запускайте на соответствующей платформе. На Linux сначала скачайте `appimagetool` и укажите путь к его исполняемому файлу:

```sh
APPIMAGETOOL=/path/to/appimagetool bash installer/build-desktop.sh linux-x64
bash installer/build-desktop.sh osx-arm64  # Apple Silicon
bash installer/build-desktop.sh osx-x64   # Intel Mac
```

`.AppImage` и ZIP с `.app` появляются в `artifacts/installer/`. Графический мастер запускает вложенный CLI для обнаружения и патчинга глав. CI проверяет запуск упакованного мастера, но не самой игры. Mac-сборка подписана ad hoc, без Developer ID и нотарификации; подпись установщика не восстанавливает подпись пропатченной игры.

## Публикация релиза

После слияния в `main` поставьте на нужный коммит тег `vX.Y.Z`, совпадающий с `AppVersion` в `installer/DeltaTranslator.iss`, и отправьте тег на GitHub. Когда сборки и проверки пройдут, workflow опубликует все четыре графических установщика в [Releases](https://github.com/portalT4/DeltaTranslator/releases). Обычный пуш ветки релиз не публикует.

## Как устроен патч

- `Code/` — GML, который встраивается в CLI при сборке. Новые блоки компилируются в конец существующих событий, а отсутствующее событие `obj_time` создаётся и привязывается к объекту. GML нельзя просто дописать к бинарному `.win`.
- `gml_GlobalScript_scr_trigger_translation.gml` определяет именованную функцию GameMaker 2.3+. Патчер регистрирует глобальный скрипт и компилирует его в одной группе с вызывающим `Step`. После записи он перечитывает архив и проверяет, что `Step` вызывает именно эту функцию.
- Игровые архивы не входят в репозиторий. Патчер распознаёт по SHA-256 два прежних образца со старой версией мода и заменяет старые вставки, чтобы не было двойного перевода. Неизвестные варианты старого патча не переписываются: используйте чистый архив.
- Патчер встраивает [два шрифта оверлея](../Fonts/Overlay/README.md): `fnt_dt_overlay_ru` на основе адаптации DubstepDude для русского и `fnt_dt_overlay` для остальных языков и меню выбора. Оригинальный `fnt_main` остаётся неизменным. Мод переводит поддерживаемые диалоги, меню с `obj_menuwriter`, варианты ответа и облачка реплик `obj_talkbubble`. Перевод облачка рисуется над ним и привязан к его позиции; в главах без этого объекта функция отключена. Мод не переводит произвольный текст, нарисованный напрямую или включённый в изображение.
- Мини-реплики `obj_smallface` и облачка `obj_couchwriter` / `obj_tennatalkbubble` используют независимые слоты HTTP и рисуются рядом с оригиналом. Известные анимированные слова `obj_funnytext` добавляются в текст диалога по именам спрайтов и не имеют своей плашки.


## Проверка компиляции без файлов игры

```bash
dotnet run --project tests/TestArchives.csproj -c Release -- --synthetic
```

Тест создаёт ресурсы с нужными именами, компилирует GML, проверяет оба атласа и проверяет, что меню перехватывает клавиши в `Begin Step` до того, как игра считывает ввод. Он не запускает игру.

## Тесты с локальными архивами

Для добровольной проверки скопируйте оригинальные архивы из своей копии DELTARUNE в локальную папку `datawin/` под именами `data_ch1.win` и `data_ch2.win`. Не добавляйте их в Git. Укажите другую папку в командах, если файлы лежат не в `datawin/`.

```bash
dotnet run --project tests/TestArchives.csproj -- datawin
dotnet build Patcher/DeltaTranslator.Patcher.csproj
python tests/smoke_cli.py --fixtures datawin dotnet Patcher/bin/Debug/net10.0/DeltaTranslator.Patcher.dll
```

Тесты проверяют чистые архивы обеих глав, сохранение исходного кода событий, привязку новых событий, шрифт, перечитывание результата, обнаружение и выбор глав, резервные копии и повторную установку. На Windows опция `--installer <путь-к-exe>` дополнительно проверяет тихую установку. Публичная сборка GitHub Actions не использует файлы игры. Компиляция и проверка ссылок в байткоде не заменяют запуск игры и проверку живого перевода.
