# DeltaTranslator

DeltaTranslator — неофициальный мод для DELTARUNE, который показывает машинный перевод поверх оригинального текста. Языки перевода: **русский, испанский, бразильский португальский (`pt`), немецкий, польский, украинский, турецкий, итальянский и французский**. Интерфейс установщика Windows доступен на **английском, русском, испанском, бразильском португальском и немецком**. Английский не входит в список языков перевода в игре.

## Что переводит мод

- Поддерживаемые реплики в мире игры и в бою, а также текст меню, выводимый через `obj_writer` или `obj_menuwriter`. Не все меню и боевые надписи используют эти объекты.
- Варианты ответа в поддерживаемых окнах выбора.
- Облачка реплик `obj_talkbubble`, в том числе в пятой главе. Перевод рисуется над своим облачком и следует за ним, отдельно от обычных диалогов. В главах без этого объекта функция отключена.
- Перевод мини-реплик и облачков Тенны появляется рядом с оригиналом. Известные анимированные вставки вроде **Lovely** переводятся в составе самой реплики, без отдельной плашки.

Мод не переводит произвольный текст на изображениях, надписи, которые рисуют другие скрипты напрямую, и неподдерживаемые элементы вроде текста песен в ритм-сценах. Исходный текст и шрифты игры не заменяются.

## Как это работает

При запросе мод читает активный поддерживаемый текст и при необходимости убирает служебные коды форматирования. Затем отправляет текст и выбранный язык в **Google Переводчик** по HTTPS; язык оригинала определяется автоматически. Машинный перевод приходит асинхронно и показывается отдельным слоем. Авторежим отслеживает изменения и не отправляет повторно тот же текст в той же активной позиции. **Нужен интернет.** Без авторежима запросы отправляются только по F5. Мод не связан с Google, разработчиками DELTARUNE или командами фанатского перевода.

| Клавиша | Действие |
| --- | --- |
| **F1** | Открыть или закрыть выбор языка; в меню используйте стрелки и **Enter** или выберите язык сразу клавишей **1–9** |
| **F2** | Переключить автопозиционирование там, где оно поддерживается |
| **F3** | Включить или выключить автоперевод (при запуске выключен) |
| **F5** | Перевести текущий поддерживаемый текст |
| **F6** | Скрыть перевод |

Горячие клавиши и состояние авторежимов отображаются в игровом меню устройства. Для русского оверлея используется адаптация Determination Mono от **DubstepDude**. Для остальных языков — Determination с дополнительными символами. См. [источники и авторов шрифтов](../Fonts/Overlay/README.md).

## Скачать и установить

Откройте [Releases](https://github.com/portalT4/DeltaTranslator/releases) и скачайте установщик для своей системы из раздела **Assets**. Перед установкой закройте DELTARUNE.

**Linux / Steam Deck и macOS:** у меня нет ни Mac, ни компьютера с Linux. С этими сборками возможны проблемы.

| Платформа | Установщик |
| --- | --- |
| Windows x64 | `DeltaTranslator-Setup-win-x64.exe` |
| Linux x64 / Steam Deck (игра через Proton) | `DeltaTranslator-Setup-linux-x64.AppImage` |
| macOS, Apple Silicon | `DeltaTranslator-Setup-osx-arm64.zip` → `DeltaTranslator.app` |
| macOS, Intel | `DeltaTranslator-Setup-osx-x64.zip` → `DeltaTranslator.app` |

- **Windows:** откройте `.exe`. Мастер по умолчанию не запрашивает права администратора; `/ALLUSERS` нужен только для защищённой папки. В тихом режиме `/CHAPTERS=1,2` ограничивает выбор; без него выбираются все найденные главы.
- **Linux / Steam Deck:** откройте `.AppImage` в файловом менеджере (на Steam Deck — в режиме рабочего стола). При необходимости разрешите запуск файла в его **Свойствах**. Система должна поддерживать запуск AppImage.
- **macOS:** распакуйте ZIP и откройте `DeltaTranslator.app` в Finder. Установщик не нотарифицирован, поэтому Gatekeeper может заблокировать его запуск. Изменение ресурсов подписанной **игры** нарушает её подпись и может помешать запуску. Мастер требует явного согласия, не переподписывает игру и не меняет Gatekeeper. Запуск пропатченной нативной игры на Mac не проверен.

В установщике выберите папку игры (**Steam → Свойства → Установленные файлы → Обзор**), не папку сохранений и не корневой `data.win`. Отметьте нужные главы и нажмите **Install**. По умолчанию главы не отмечены. Терминал и отдельная установка .NET не нужны.

## Совместимость, обновление и удаление

Патчер дописывает мод в выбранные архивы глав, не скачивает игровые файлы и не меняет сохранения. Он проверяет результат перед заменой и сохраняет оригинал рядом как `.deltatranslator.bak` или `.deltatranslator.<SHA-256>.bak`. GitHub Actions собирает установщики без игровых архивов. Проверки архивов глав 1 и 2 требуют локальной копии игры; работа на всех платформах и версиях не гарантируется. Старые демо с одним общим архивом, мобильные и консольные порты не поддерживаются.

Чтобы удалить или обновить мод, закройте игру и восстановите оригинальные архивы той же версии или проверьте файлы в Steam. На Mac при восстановлении подписанного пакета переместите добавленные `.bak` за пределы `.app`. Для обновления установите новую версию DeltaTranslator на чистые архивы.
